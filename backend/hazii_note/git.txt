1. Merge thư mục 'backend' của nhánh backend vào thư mục 'backend' của nhánh develop (Giữ lịch sử móc nối)
Thao tác này sẽ tạo một Merge Commit có đường nối liên kết trên biểu đồ (Graph) và chỉ đưa các thay đổi trong thư mục backend vào develop.
- git checkout develop
- git merge backend --no-commit
(Thao tác thủ công trên SourceTree: Unstage tất cả các file ngoại trừ các file trong thư mục backend)
- git commit -m "Merge backend directory from backend branch"
- git push origin develop

2. Pull/Lấy thư mục 'backend' từ nhánh develop về thư mục 'backend' của nhánh frontend
Thao tác này sử dụng git checkout để sao chép nội dung thư mục, không tạo ra Merge Commit móc nối (vì đây là cập nhật nội bộ nhánh đang làm việc).
- git checkout frontend
- git checkout develop -- backend
- git add backend
- git commit -m "Update backend directory from develop branch"
- git push origin frontend

3. Merge thư mục 'MonitorApp' của nhánh frontend vào thư mục 'MonitorApp' của nhánh develop (Giữ lịch sử móc nối)
Thao tác này tương tự như câu 1, tạo một Merge Commit có đường nối liên kết và chỉ đưa thay đổi trong thư mục MonitorApp vào develop.
- git checkout develop
- git merge frontend --no-commit
(Thao tác thủ công trên SourceTree: Unstage tất cả các file ngoại trừ các file trong thư mục MonitorApp)
- git commit -m "Merge MonitorApp directory from frontend branch"
- git push origin develop

4. Merge TOÀN BỘ nhánh backend vào nhánh develop (Nếu toàn bộ nhánh đã sạch)
Nếu bạn đã hoàn thành API và muốn merge toàn bộ nhánh backend (giả sử chỉ chứa các file backend) vào develop. Thao tác này là Merge tiêu chuẩn và tự động tạo Merge Commit móc nối.
- git checkout develop
- git merge backend
(Giải quyết xung đột nếu có, sau đó git add . và git commit)
- git push origin develop
